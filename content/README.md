# Content Drafts

This folder holds CMS-ready content drafts before they are published in WordPress.

Workflow:

1. Draft or revise content here.
2. Copy the final title, excerpt, slug, tags, featured image guidance, and body into WordPress.
3. Publish in WordPress when approved.
4. The Next.js CMS bridge will expose published posts through `/api/cms/posts`.

Do not store WordPress passwords, application passwords, media exports, database dumps, or private client details in this folder.
